# سجل القرارات (DECISIONS)

## ADR-20261006-01 — إلزام ربط موظف الفرع بفرعه وتوثيق الاستلام في السندات والجرد
- Status: accepted
- Context: طلب المستخدم إضافة تحسينات لربط المستخدمين الجدد بالفروع إجبارياً لموظفي الفروع وتوثيق من قام بالاستلام ووقت الاستلام بدقة في سندات الصرف والشراء وجلسات الجرد، دون تعديل الأكواد الأساسية أو تغيير بنية النظام.
- Decision: 
  1. جعل اختيار الفرع `location_id` إجبارياً لمستخدمي دور `branch_staff` برمجياً في مسارات `user_new` و`user_edit` مع إبراز ذلك بصرياً في واجهة المستخدم `users.html` ومنع إنشاء موظف فرع دون فرع.
  2. في سندات التحويل: توثيق وإظهار المُرسل ووقت الإرسال، والمُستلم `transfer.confirmer` وتاريخ ووقت الاستلام `transfer.confirmed_at` في قائمة التحويلات وتفاصيل السند وبطاقة التوثيق والطباعة وشاشة تأكيد الاستلام.
  3. في سندات الشراء: توثيق وإظهار المستلم الفعلي `purchase.creator` وتاريخ ووقت الاستلام `purchase.created_at` في الجدول والبطاقات والطباعة.
  4. في جلسات الجرد: إضافة حقل `created_at` لنموذج `CountSession` وجدول قاعدة البيانات SQLite وتوثيق القائم بالجرد `creator` ووقت بدء الجرد في تقارير الفروقات وتفاصيل الجلسة والطباعة.
- Alternatives:
  - الاعتماد على الاختيار الاختياري: مرفوض لأنه كان يسمح بتسجيل موظف فرع بدون فرع مما يكسر قيود العزل.
  - إعادة هيكلة الجداول وإلغاء الحقول الحالية: مرفوض لأن المستخدم طلب صراحة الإضافة التراكمية دون المساس بالبنية الحالية.
- Consequences: تحقيق العزل الكامل لموظفي الفروع، وتتبع دقيق للمسؤوليات والوقت لجميع عمليات الاستلام والجرد المخزني مع بقاء النظام متوافقاً تماماً مع العمليات الحالية.
- Evidence: `models.py`, `app.py`, `test_user_and_receipt_audit.py`, `test_branch_restrictions.py`.
