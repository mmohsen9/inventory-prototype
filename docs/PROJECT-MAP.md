# خارطة المشروع: inventory-prototype

> آخر تحقق: 2026-10-06 — مستخرج ومتحقق من الكود المصدري وقاعدة البيانات

## الغرض
نظام متكامل لإدارة ومطابقة حركات المخزون والمشتريات والتحويلات والجرد الدوري لمستودعات وفروع شركة رفاء مع مزامنة فوديكس (Foodics API).

## التقنية والتشغيل
| البند | القيمة | الدليل |
|---|---|---|
| إطار العمل ولغة البرمجة | Python 3.11+ / Flask / Jinja2 / Vanilla CSS | `app.py`, `requirements.txt` |
| قاعدة البيانات | SQLite (`instance/rafa_inventory.db`) | `models.py`, `instance/` |
| أمر التشغيل المحلي | `python app.py` (يعمل افتراضياً على المنفذ 5000) | `app.py` |
| أمر التحقق والاختبار | `python test_branch_restrictions.py` | `test_branch_restrictions.py` |
| بيئة النشر المستهدفة | Render Web Service + Persistent Disk (`/var/data`) | `PRODUCTION-DEPLOYMENT-PLAN.md` |

## البنية والمكونات
- `app.py`: موجه المسارات والمنطق التشغيلي للنظام والمصادقة والتقارير.
- `models.py`: نماذج قاعدة البيانات (المستخدمين، المواقع، الأصناف، الفواتير، التحويلات، الجرد، طابور المزامنة).
- `sync_queue.py`: إدارة طابور مزامنة العمليات والترحيل إلى Foodics API مع آليات إعادة المحاولة ومعالجة الأخطاء.
- `templates/`: قوالب واجهات المستخدم (لوحة التحكم، المشتريات، التحويلات، الجرد، إدارة المستخدمين، مراجعة المحاسب).
- `static/`: الأنماط (CSS) وسكربتات الواجهة والبحث الفوري والباركود.

## البيانات والعلاقات الرئيسية
- `User`: مستخدم النظام (معرف، اسم، دور `admin`/`accountant`/`warehouse`/`branch_staff`، ارتباط بالموقع `location_id` إلزامي لموظف الفرع، كلمة مرور، بريد).
- `Location`: المواقع والفروع (مستودع رئيسي `warehouse`، فرع `branch`، معرف فوديكس `foodics_id`).
- `Item` & `StockBalance` & `StockMovement`: الأصناف، الأرصدة الحالية في كل موقع، وسجل الحركات المخزنية اللحظية.
- `PurchaseTransaction` & `PurchaseLine`: سندات الشراء والتوريد من الموردين، الأصناف المستلمة، المرفقات، المستلم ووقت الاستلام.
- `TransferOrder` & `TransferLine`: سندات التحويل بين المواقع، المرسل ووقت الإرسال، المستلم ووقت الاستلام، وحالات المطابقة والفروقات.
- `CountSession` & `CountLine`: جلسات الجرد المخزني الدوري، المسؤول عن الجرد، تاريخ ووقت الجرد اللحظي `created_at`، مطابقة الفعلي بالدفتري، والتسويات.
- `SyncQueue` & `SyncLog`: طابور وجدول مزامنة فوديكس للعمليات المعتمدة.

## الأدوار والصلاحيات
1. **مدير النظام (admin)**: صلاحيات كاملة للنظام، إدارة المستخدمين، الترحيل والاعتمادات.
2. **المحاسب (accountant)**: مراجعة واعتماد الفواتير، اعتماد فروقات التحويلات والجرد، ومعالجة طابور المزامنة.
3. **أمين المستودع (warehouse)**: تسجيل فواتير التوريد، إنشاء شحنات التحويل وصرف المواد للفروع، وجرد المستودع.
4. **موظف الفرع (branch_staff)**: مقيد إجبارياً بفرعه المحدد، استلام وتأكيد الشحنات الواردة لفرعه مع توثيق اسمه ووقته، وتنفيذ الجرد الدوري لفرعه فقط.

## التكاملات الخارجية
- **Foodics API**: مزامنة الأصناف، الموردين، الفروع، إنشاء فواتير الشراء، طلبات التحويل، وجلسات الجرد عبر طابور المزامنة وسجلات `SyncLog`.
