# قاعدة مطابقة وتطبيع وحدات القياس (Unit Normalization & Matching Rule)

## الخلفية والهدف
في فوديكس وأنظمة المخزون، يُسجل الصنف بوحدة تخزين أساسية (`storage_unit` مثل: `لتر` أو `كجم` أو `حبة`) ووحدة مكونات (`ingredient_unit` مثل: `مل` أو `جرام`).
عند الشراء، يبيع الموردون الأصناف بوحدات طلب خاصة بهم (`ItemSupplier.order_unit` مثل: `1 لتر` أو `2.85 لتر` أو `كرتون 12 حبة`).

## القواعد الإلزامية:
1. **عدم رفض وحدات الموردين التعبوية:**
   - إذا اختار الموظف صنفاً مدخلة وحدته كـ `1 لتر` أو `2.85 لتر` أو `كرتون` وكان الصنف مخزناً بـ `لتر`، فإن بوابة التحقق `validation_gate.py` تطبع الوحدة تلقائياً بإزالة البادئات الرقمية والأرقام والكميات التعبوية.
2. **المطابقة الذكية مع المترادفات:**
   - يتم قبول المترادفات اللغوية تلقائياً:
     - `لتر` = `1 لتر` = `liter` = `ltr` = `l`
     - `كجم` = `كيلو` = `كيلوجرام` = `kg` = `1 كجم`
     - `حبة` = `قطعة` = `piece` = `pc` = `each` = `1 حبة`
     - `مل` = `مليلتر` = `ml`
     - `جرام` = `غرام` = `g`
3. **عدم إظهار أي تحذير تعارض:**
   - يمنع منعاً باتاً إظهار تحذير `وحدة القياس المدخلة لا تطابق وحدة الصنف في فوديكس` إذا كانت الوحدة مطابقة لوحدة التخزين أو وحدة المكونات أو أي من وحدات الطلب المعتمدة للموردين المرتبطين بالصنف في `item_suppliers`.
4. **القيم الفارغة والتلقائية:**
   - تقبل القيمة الفارغة أو نص `الوحدة (تلقائي)` أو `تلقائي` وتعتمد مباشرة وحدة التخزين دون تنبيه.
