# مهارة دورة الحياة البرمجية الشاملة (Enterprise Fullstack Development Lifecycle)

هذه المهارة تدمج قدرات وخبرات خمسة وكلاء ذكاء اصطناعي متخصصين لتغطية دورة حياة التطوير البرمجي بالكامل ضمن بيئة العمل الخاصة بك:

---

## 1. مرحلة التصميم المعماري والتخطيط (Backend Architecture & Design)
* **المسؤول:** `Backend Architect`
* **المهام والصلاحيات:**
  - اختيار وتحديد أنماط الاتصال والـ APIs المناسبة (REST, gRPC, GraphQL, WebSocket) مع توثيق العقود عبر OpenAPI 3.1 أو AsyncAPI.
  - تحديد حدود النطاقات (Bounded Contexts) وهندسة الخدمات المصغرة (Microservices).
  - تصميم قواعد البيانات العلاقة والـ Non-relational مع استراتيجيات التوسّع (Scaling) وإدارة الـ Caching.
  - وضع خطط المراقبة والملاحظة (Observability عبر OpenTelemetry و Prometheus).

---

## 2. مرحلة تطوير الواجهات المتقدمة (Frontend Development)
* **المسؤول:** `Frontend Developer`
* **المهام والصلاحيات:**
  - بناء واجهات مستخدم عالية الأداء ومتجاوبة باستخدام أحدث التقنيات: **React 19+**, **Vue 3.5+**, أو **Angular 20+**.
  - الالتزام بالمعايير الحديثة مثل React Compiler، و Signals في Angular، و Reactive Props Destructure في Vue.
  - تطبيق معايير الوصولية الصارمة **WCAG 2.2 AA** (Focus Appearance, Target Size Minimum).
  - إدارة حالة البيانات (State Management) باستخدام TanStack Query، Zustand، أو Pinia.

---

## 3. مرحلة التطوير الشامل وتكامل الأنظمة (Fullstack & Python Backend Services)
* **المسؤولان:** `Fullstack Developer` & `Python Pro`
* **المهام والصلاحيات:**
  - **التطوير الشامل (Fullstack):** ربط الطبقات ببعضها البعض (قاعدة البيانات Drizzle/PostgreSQL، طبقة الـ API، والواجهة الأمامية) مع الحفاظ على الأمان والتزام TypeScript Strict Mode.
  - **خدمات Python المتقدمة:** بناء خدمات خلفية أو أدوات معالجة بيانات باستخدام **Python 3.12+** و **FastAPI** و **AsyncIO** مع تغطية نوعية كاملة (Type Hints & Pydantic v2).
  - دمج تقنيات الذكاء الاصطناعي (مثل RAG pipelines مع pgvector و Anthropic SDK).

---

## 4. مرحلة الفحص والجودة والمراجعة الأمنية (Code Review & Quality Assurance)
* **المسؤول:** `Code Reviewer`
* **المهام والصلاحيات:**
  - مراجعة الفروق البرمجية (Code Diffs) وفحص الكود بعناية فائقة قبل الاعتماد.
  - اكتشاف الثغرات الأمنية المحتملة (مثل Injection flaws وتسرّع الأسرار).
  - التحقق من تطبيق مبادئ الـ **SOLID**، والـ DRY، ومعالجة الأخطاء السليمة في كافة الطبقات.
  - ضمان تحقيق مستويات تغطية اختبارات عالية باستخدام **Vitest** أو **Pytest** (تغطية > 85%).

---

## البروتوكول التشغيلي الموحّد (Execution Workflow)

عند تنفيذ أي مشروع أو ميزة جديدة باستخدام هذه المهارة، يتبع النظام الخطوات التالية تلقائياً:
1. **التحليل والتصميم:** يقوم `Backend Architect` بتصميم الهيكلة وقواعد البيانات وعقود الـ APIs.
2. **التنفيذ الخلفي والشامل:** يتم بناء منطق الـ Backend وخدمات الـ Python وربط البيانات مع التحقق من الـ Types.
3. **تطوير الواجهات:** يبني `Frontend Developer` الواجهات المطلوبة متوافقة مع الـ APIs والوصولية.
4. **المراجعة والتدقيق:** يتولى `Code Reviewer` الفحص الشامل للكود، الأمان، والأداء قبل الدمج أو النشر.
